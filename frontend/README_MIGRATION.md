# QDR V4 正式组件化前端（v4.3 完整图表 + 全业务模块还原版）

## 补齐的图表与业务模块
- **总览**：四层门控色条、模拟净值 vs SPY 曲线、行业与现金环形图、候选表（涨跌色+概率进度条）、A/B/C/D 消融表、逐日评分卡。
- **L1 市场**：4 语义 KPI、上涨/下跌风险双折线、六大体系标准化柱状图、收益分布柱状图、概率校准曲线、维度明细表。
- **L2 风格**：Z-Score 双向柱状图、多日轮动折线、Lead-Lag 领先性检验柱状图、ΔIC 显著性表。
- **L3 个股 Alpha**：每日选股与多因子组合勾选预检；自定义因子实验室 + 冗余相关性诊断 + 五分组/滚动 IC 双图；策略激活/预检/冻结 + Walk-Forward 净值与水下回撤双图；历史信号复盘表。
- **L4 持仓风控**：个股盈亏贡献图、行业敞口 vs 30% 上限图、止损距离红橙绿预警、持仓相关性热力矩阵、模拟成交流水表。
- **数据中心**：数据仓库同步与覆盖率进度条、PIT 证券池、公司行为与快照审计、V4 数据包 SHA256 准入。

## 运行与构建
```bash
cd frontend && npm install && npm run dev   # 代理直连 127.0.0.1:8766；顶栏可切「样例」开关预览满屏图表
npm run build                               # 输出至 src/quant_research/assets/dist/
```
