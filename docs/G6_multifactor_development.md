# G6 · 真实研究产物驱动的多因子策略配置（首批代码改造）

## 已实现（代码层）

- `StrategySpec` 支持 2–8 项已完成因子实验及正权重（合计 100%），旧版 `factor_experiment_id` 单因子策略保持兼容。
- 每项实验必须已完成、产物哈希有效且属于 Yahoo 当前版本历史探索；跨实验比较严格要求相同价格数据快照 SHA256、来源、复权口径、股票池成员、研究范围及评估协议。
- 禁止重复使用同一因子版本；组合缺失按「全部成分都有值」取交集，不做填零、前向填充或伪造收益。
- 新增 `/api/v1/strategies/{id}/composite` 只读接口。后端读取已有真实 `features.parquet` 和 `labels.parquet`，重新核验原始实验产物哈希；按每日横截面分位排名加权，并报告验证期间的平均 Rank IC、有效观测天数与验证期末最近排名。
- v4 策略工作台支持逐项选择因子、设置权重、保存、复制为新版本、冻结和点击「计算真实多因子研究排名」。
- 与旧策略一样，多因子组合 **不允许** 因为保存、冻结或有 IC 数据，就自动成为交易建议、历史回测、模型校准或模拟成交输入。

## 必须明确的证据等级

`RETROSPECTIVE_COMPOSITE_RESEARCH_ONLY`：使用真实观察到的历史价格和因子数值做当前版本探索。`historical_decision_eligible=false`、`research_grade=false`、`execution_ready=false`、`real_orders_enabled=false`、`sealed_test_used=false`。Rank IC 是价格代理统计，不包含成交模拟或成本；不进行多重试验校正。

## 尚未完成

1. **合格历史个股数据库**：PIT 股票池、永久 ID、退市和公司行为、历史首次到达时点仍缺。
2. **投资可执行的多因子 Alpha**：当前仅展示历史横截面加权排序，无实时模型信号与成本后预期收益。
3. **四层结合**：市场状态和经典风格过滤尚未作为可验证策略依赖接入。
4. **严格回测、前向模拟**：不解除此前真实数据的安全门槛。
5. **真实环境验收**：本代码包不包含用户本机 `data/` 与可合法读取的原始供应商缓存，不能声称真实历史组合 IC 已运行通过。

## 在本机进行真实验证

1. 使用现有 `data/managed/factor_lab/registry.sqlite3` 找到同一数据快照下两个以上完整因子实验。
2. 从策略页面选择「多个因子」，选择 2–8 个实验并将权重设置为 100%，保存策略。
3. 点击「校验来源一致性」。来自不同历史快照或研究协议的组合应该显示准确阻断；不允许偷偷重新加载当前行情补足。
4. 通过后点「计算真实多因子研究排名」，确认验证期 Rank IC、有价值数量和所展示数据来源都由后端真实原始产物计算。
5. 重跑相同版本输出应一致；改坏任意原始特征的哈希，必须出现 BLOCKED。
6. `uv run --locked pytest -q tests/test_multifactor_contract.py tests/test_strategy.py`。

本轮仅新增单独研究能力，不购买数据、不解封最终测试、不连接实际交易。
