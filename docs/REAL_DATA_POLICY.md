# REAL_ONLY正式数据策略

v2.1及用户当前指令替代旧fixture/demo规范。CLI、API、因子面板、仓库插入、模型输出和报告入口拒绝非真实来源。运行时不提供生成器或环境变量绕过开关；旧生成器和旧测试移至archive目录，不打包、不执行、不计验收。旧数据库与输出不删除；正式查询明确选择真实来源，报告下载还须来源和文件哈希匹配。

来源名不是研究级资格。真实Yahoo只允许当前版本观察/探索；不当作raw或历史PIT。价格行需要SHA256及时间顺序；元数据来源检查不等于已跨来源核验。历史证券身份、公司行为、来源发布时间仍需要G1–G3真实证据。未知时点不倒填。

执行能力在G4证据接线前失败关闭，返回EXECUTION_EVIDENCE_MISSING。缺行情返回NO_REAL_DATA，非真实源NON_REAL_SOURCE_REJECTED；HTTP错误分别保留HTTP_401/403/422/429/5xx。无凭证MISSING_CREDENTIALS，不发送网络请求、不补假数据。

市场集成必须回放真实缓存与原始hash。许可/缓存缺失或内容不完整时pytest skip理由含BLOCKED，并在阶段文档单列；不能把跳过计作通过。旧109测试不作为本次依据。数学常量测试和算法在真实样本上的固定种子不属于合成行情许可。

生产UI禁止旧无manifest、无真实source、无artifact hash或哈希不匹配的报告。七个尚未完成功能页面明确显示BLOCKED/N/A，不展示市场值或收益；总览和数据页只展示现有真实查询。此为空态整改，非完整九页产品验收。

不实盘、不购买、不创建账户、不自动解封最终测试。凭证只由用户在本地环境配置，绝不在聊天/代码/日志中索取明文。修订缓存、重算模型和任何输出必须保留新版本，不静默改旧信号。
