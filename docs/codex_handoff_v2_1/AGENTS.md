# Codex 项目执行规则（REAL_ONLY）

- 在**已有仓库**工作：先运行 `pwd`, `git status`, `git rev-parse HEAD`，审计数据链路；不得重建仓库、覆盖既有项目或无请求自行部署。
- **生产路径绝不接收合成/随机/fixture/mock/demo 市场记录、历史收益、信号、成交或持仓。** 没有真实数据时 fail closed：`NOT_READY` / `BLOCKED` / `N/A`。
- 数学单测可以使用字面常量；市场数据集成测试必须使用有来源元数据和哈希的真实历史记录，许可不允许存档则测试 BLOCKED，不伪造通过。
- 任何信号必须具真实 `available_at <= decision_at` 的证据；不明发布时间拒绝。分清数据的事件时间、来源发布时间、抓取时间、首次可用时间。
- 只用有证据的 raw OHLCV 估算模拟成交，且必须清楚标记 `MODELLED_FILL`；不准称为券商实际成交。公司行为、退市、跨期 ID 要审计。
- 不采购服务、不创建账户、不修改交易参数、不自动发实盘单、不向日志或代码写密钥。缺权限时输出最小所需的人类操作。
- 严禁自行解封最终测试集；市场/风格模型无预测优势时明确如实记录，而不是搜索参数直到盈利。
- 每个阶段出具文件变更、实际执行的测试、通过/失败/阻断、数据来源证据、下一阶段依赖。无测试记录不能声称完成。
- 本目录修复计划 `G0→G5` 的优先级高于 v1.1 文档残留文本，九页 UI 与研究算法需求仍须保持。
