# 美股多层量化研究系统 · Codex 统一交付文件夹 v2.1（REAL_ONLY）

**这是替代旧 v1.1 ZIP 与单独 v2.0 整改文件的唯一交付包。** 请将整个文件夹放入**现有 Codex 项目仓库**的 `docs/codex_handoff_v2_1/`，不要创建新项目或覆盖用户正在开发的源代码。先阅读本页和 `给Codex的启动指令.md`。

## 文档优先级（冲突时从上往下）

1. `AGENTS.md`：必须执行的 REAL_ONLY、不可购买和验收约束。
2. `01_统一规范/真实数据整改与15项修复.md`：G0–G5 真实数据整改、证券身份、PIT、事件账本、数据能力准入。
3. `01_统一规范/实施顺序_依赖关系与验收.md`：在**现有仓库**逐阶段执行的顺序、依赖和交付证据。
4. `02_技术与研究/核心研究开发规范_REAL_ONLY.md`：四层模型、因子库、研究统计与回测时间语义。
5. `03_UI与交互/UI交互与使用说明_REAL_ONLY.md`：九个页面、真实数据空态、API 与操作流程。
6. `04_原始问题与证据/卡点清单_原始输入.md`：原始问题证据，不作为工程指令优先级。

## 与旧版的区别

- 旧交付包中 `量化研究系统_交互原型_DEMO.html` 与首页截图含虚构数据，本包**不包含它们**。
- 新的 `03_UI与交互/真实数据空状态原型.html` 仅用于查看布局、导航和真实数据未就绪状态；**不含行情和回测结果，不会连接 API**。
- 不再将 P0–P6 当作从零开发路线；现有仓库按 G0–G5 修复。四层模型、九个页面作为最终功能需求继续保留。
- 系统仅接受可溯源真实行情/财报/证券历史；无真实数据时显示 `BLOCKED / NOT_READY / N/A`；历史模拟成交必须明确标注为模型假设，不能写成真实成交。

## 交付边界

该文件夹是**规格与修复指导**，不包含 Codex 已执行的源代码修改、历史市场数据或真实测试结果；验收必须由 Codex 在现有仓库真正运行后填写。禁止实盘真实下单。

## 快速开始

1. 解压，把文件夹完整复制进现有仓库（建议 `docs/codex_handoff_v2_1/`）。
2. 把 `给Codex的启动指令.md` 原文贴给 Codex，让它先完成 G0 审计。`AGENTS.md` 可按需复制到仓库根目录，但**先检查现有 AGENTS.md 并合并**，不要直接覆盖。
3. 要求 Codex 逐阶段写出 `05_验收模板/阶段验收记录模板.md` 中规定的实际证据。遇到 API 凭证与许可阻断时请你本地配置，不要把密钥发给 Codex。
