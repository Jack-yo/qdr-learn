## 必查证据

- [ ] 实际运行日志（非文档中的预期结果）
- [ ] `REAL_ONLY` 正式入口阻断测试
- [ ] 同一输入数据 hash 重跑结果一致
- [ ] 历史时点/PIT/证券身份/退市边界测试
- [ ] raw 与复权价格口径审计
- [ ] 无密钥、迟到数据、接口失败情况下的真实空态
- [ ] 九个页面 API 响应含 source/as-of/version/coverage
- [ ] 不存在虚假成交或假胜率输出
