# G0–G5 统一执行顺序与验收（现有仓库，非重建项目）

## 总原则

1. **先真实数据，后功能解锁**：前端与 API 通过后端 DatasetBundle + CapabilityGate 判定资格，不根据 `provider=fixture` 或供应商白名单直接绕开。
2. **功能分级不是数据造假许可**：OBSERVATION / EXPLORATORY / RESEARCH_GRADE / FORWARD_PAPER 都必须使用真实、可溯源的数据；前两档限制结论，后一档没有历史现成成交。
3. **优先解除工程阻断**：原 P3/P4 能做当前版本回溯，不能把它包装为历史 PIT 决策；P5/P6 不得用假数据解锁。
4. **每个“已完成”必须附实际运行命令、日志、真实覆盖率、证据 hash 与失败项目**，否者标 BLOCKED。

## 任务依赖图

G0（真实数据禁用门槛 + 仓库审计）
→ G1（Alpaca 账户只读探测、SIP raw 完整历史、分页、缓存/到达时间）
→ G2（稳定证券 ID、历史名册/退市、公司行为和原始成交）
→ G3（SEC 原申报时间、SIC、质量/规模、French 因子发布口径）
→ G4（统一数据接线 → 四层模型 → 回测/日报/UI/前向影子）
→ G5（样本外与一次性最终测试、实际调度与恢复、前向真实交易日观察）

G2 与 G3 可以在 G1 提供真实行情接口后分支并行；G4 的某些观察能力可提前上线，但对应数据门槛不得降低。

## 数据源技术验证清单

- 行情：`feed=sip`, `adjustment=raw`, 明确时区/完整交易日；Basic 权限内历史必须截至允许的延迟时点；对 401/403/422/429/5xx 独立错误码。
- SEC：从原始 10-Q/10-K/8-K 文本/申报数据对应 accession/accepted_time 建时间，夜间聚合包只能辅助重建，不能把今天获取日当历史公开日。
- 股票池：按历史有效期/当时可见时间重建，不把当前活跃标的名单回填过去；代码复用需实体身份映射。
- 事件：拆股、现金分红、并购、退市真实事件账本，不可既复权收益又加一次分红。
- 因子：French 历史因子和 ETF 风格代理必须标记不同定义、实际发布可用时间。
- UI：每张图展示 source/as-of/data_cutoff/model_version/coverage；缺数据不显示 0 或虚构百分比。

## 验收必须输出的指标

`source_coverage`, `historical_identity_coverage`, `delisting_settlement_coverage`, `corporate_action_reconciliation`, `PIT_publication_check`, `time_leakage_check`, `raw_adjusted_separation`, `execution_assumption_disclosure`, `ui_real_only_e2e`。

每个字段输出 `PASS|FAIL|BLOCKED`、样本数量、证据、是否允许提升能力级别。数据未满足仍可交付受限功能，但不能称为“全市场严谨回测完成”。

## UI 与功能联系

九页保留：总览、市场、风格、因子实验室、策略工作台、回测中心、每日信号、模拟组合、数据与设置。新用户首页先进入真实数据设置与健康度；无真实数据时图表空态，仍可导航阅读和保存**不执行的配置草稿**。所有模型计算都由后端真实数据驱动，前端不承载公式计算。
