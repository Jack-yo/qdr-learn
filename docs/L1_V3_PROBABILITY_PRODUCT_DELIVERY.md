## 产品页面（保留原 QDR 深色设计）

主路由：/studio#market。自上而下：紧凑的市场结构状态栏、H1/H3/H5 上涨/震荡/下跌研究估计、所选期限的逐项数据计算追溯、可滚动的各领域原始观测、前向预测结果核验、12 维数据覆盖以及旧版 E01/E02/E03 入口。没有使用大面积市场结论文案、无关的屏幕标签或随机演示数值。原 L2/L3/L4 不修改。

## 前端数据接口

- GET /api/v1/l1/v3/latest：最新已冻结研究快照，纯文件读取。
- GET /api/v1/l1/v3/status：上次模型训练、是否到期、最新冻结日期、任务错误，纯文件读取。
- GET /api/v1/l1/v3/outcomes：到期后真实情景和评分，纯文件读取。
- GET /api/v1/l1/v3/history：轻量历史预测快照列表。
- GET /api/v1/l1/v3/overview：兼容别名，只读。过去的 archive/refresh 查询不再许可通过 GET 写盘。
- GET /api/v1/l1/v2/overview?horizon=3、/api/v1/l1/v2/official、/api/v1/l1/v2/extended：12 维原始市场监测与官方公开数据，采用旧有渐进加载。

页面永远不触发历史大窗口数据下载、模型训练或新预测的落盘。单独原始数据 API 仍可查询必要的 530 天样本和最新源观测，跟研究概率引擎训练是独立工作负载。

## 后端计算与任务

历史行情提供方 Alpaca：独立配置 QDR_L1_HISTORY_FEED=sip/iex，快照 QDR_L1_FEED=delayed_sip。训练时请求五个核心 ETF 的多年拆股调整日线；训练期间严格控制标签结束时点、校准时间窗与滚动样本外窗口。正式保存标准化器、3 类 Logit、温度与验证结果到不可覆盖的 JSON 模型档案，并以 SHA256 标识。

每个交易日收盘并满足数据延迟后，独立任务读取持久化模型，获取近期行情，计算本次特征→原始三分类概率→温度校准→冻结研究快照；期限结束后追加 H1/H3/H5 真实结果与 Brier。每 35 个自然日左右自动考虑重训。

使用 OS 级跨进程文件锁、严格来源及时点门控、失败日志、Windows Task Scheduler/Linux systemd 用户定时器安装脚本，任务进程意外退出后 OS 锁释放。历史行情缓存依旧体积和 TTL 有限，没有完整行情仓库。

## 状态与风险控制

研究状态始终 RESEARCH_ONLY，historical_pit_verified=false，
admitted_probabilities=null，execution_eligible=false；当前回放样本不是历史 PIT 审计或交易胜率承诺，公开 CFTC/Cboe/OFR 的最新观测不直接混入研究模型。训练条件不足、源过期、损坏文件、并发和缺失会阻断新预测，显示旧数据或明确不可用状态，不捏造概率。

## 可核验交付与仍受环境限制的部分

代码：模型持久化、每日预测与调度、只读 Web、前端状态、预测审计/结算、历史行情修正、离线测试、本地验收脚本均已编写。

需要用户本地执行：安装依赖、配置 Alpaca 只读 API、使用真实 SIP 或 IEX 历史行情进行实际完整训练、检查计划任务是否在用户操作系统持续触发、观察下一交易日的到期评价。以上不是 ChatGPT 端能够代替用户本机完成的操作；不能把脚本存在等同于已经在本地成功运行。
