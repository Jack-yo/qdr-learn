The `feature_coverage.csv` generated by a research run reports observed
feature rows, rather than claiming provider permission or a point-in-time
historical vintage. For calculated features the cutoff is not substituted for
an unknown source availability time. All entries remain ineligible until the
required independent provenance and PIT checks are completed.

A separate single-session audit of the verified 2026-11-13 close snapshot is at
`outputs/l1_snapshot_audits/2026-11-13/feature_coverage.csv`. It finds 2 of
57 features with values from that one session; rolling windows deliberately
remain unavailable. These numbers are not estimates of full historical feed
coverage. Run it with `python -m quant_research.workflow.l1_snapshot_audit
--asof 2026-11-13 --output <new-output-directory>`.

The current-vintage fallback verifies the source bundle and shows only SPY
same-session open-to-close return and close location; it does not use raw
multi-day prices as corporate-action-adjusted history. The new daily stage
records the one-session audit but does not train, freeze or settle a model.

On the current Windows workstation, `QDR-L1-Daily-Observation` is registered
for 06:30 China time on Tuesday through Saturday, using `scripts/run_daily.ps1`.
The task requires an interactive user session and its first scheduled run has
not yet occurred. The script itself checks the XNYS close-to-next-open window;
the separately executed run `34a881e9-82de-4b04-9e4d-702436da9f64` completed
the new audit stage for 2026-11-13 without producing a forecast.
