# 冻结的基础协议

信号 T close 后；所有输入须在 signal_time 前已可用。默认信号延迟 15 分钟是 P0 演示假设，不保证供应商在此时完整发布。

H∈{1,3,5} 独立实验：T+1 open 建仓，T+H close 退出；H=1 当天开到收。标签只用于离线评价，不能混入决策输入。成交必须使用 raw，后续收益计算需单独处理拆股分红。成本/跳空/停牌/退市规则在 P5 实施前冻结和测试。

历史财报使用 available_at 而非 period_end；French 不明发布时间只能延迟或事后归因；当代成分股不能冒充历史股票池。

样本划分、目标、成功标准和调参空间在 P2/P4 前形成实验配置，保持最终测试封存；P0 fixture 不构成真实研究样本。未来验证需时间顺序、训练内变换、walk-forward、按标签实际起止 purge 与不小于最大持有期 gap。

关键业务规则由主代理/用户决策，不能为追求显著性或测试通过而自动修改。失败结果照实报告 NOT_READY；无真实订单接口。

P2 固定配置为 configs/experiments/p2_factors.yaml：仅 2017–2024，2025 起封存；训练末尾另留 5 交易日 gap，按实际退出日 purge 跨分区标签。P2 没有模型训练或窗口择优，成功标准是工程与公式正确。

用户授权 Yahoo 替代来源后的 retrospective 仅当前版本历史描述，不产生合法历史决策特征；所有 decision_eligible=false，Yahoo 正式 raw 标签和净收益保持为空，仅 proxy 列供探索。strict 不放松原信息可用性规则。后续训练/回测不能静默消费 retrospective 行。

P3–P6 配置 baseline.yaml 已冻结：季度滚动，1260-session训练窗口/至少252session，Ridge alpha=1、Logistic C=1、5session gap及实际label时间purge。市场风险事件是收益<-2%，5%训练无条件分位仅作未校准风险描述；0.10下行筛选阈值、风险预算和5/10/20/50bps/侧场景为预设待验证规则。
