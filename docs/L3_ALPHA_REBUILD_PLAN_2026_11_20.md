# QDR L3 · 个股 Alpha 模块重构实施计划

- 制定日期：2026-11-20
- 代码审计基准：`main@1a4853049e096141da600425344a4b5fa837587e`
- 本文件是需求/架构/验收基线，**不表示功能已完成或数据已获得交易资格**。
- L3 定位：真实美股股票池中的 **1/3/5 交易日 Alpha 研究与机会发现**；L4 独立决定是否交易、仓位、退出。默认关注 H3，H1/H5 可切换。
- 统一时钟：T 收盘后冻结已知特征；若满足计划条件，最早 T+1 开盘可尝试入场；评价期限为 T+H 收盘。使用 XNYS 日历，处理非交易日与跨交易日事件。

## 1. 目标与非目标

**每天只回答六件事：**
1. 今天真实可观察的个股池是多少，为什么剔除了其他股票？
2. 哪些股票出现了初步 Alpha 机会、哪些正在形成、哪些机会失效？
3. 这些机会的超跌/压力衰竭/转强过程及行业相对证据是什么？
4. H1/H3/H5 预期总收益、相对基准超额收益、上涨及下行风险概率是多少？置信与校准资格如何？
5. L1 市场与 L2 风格条件对同一股票的预测是否产生经 OOS 验证的增量？
6. 今天最终是“观察、待确认、已触发研究条件、无合格机会”中的哪一种？后续兑现如何？

非目标：不在 L3 内下单，不把因子加权分位称为收益预测，不替 L4 给出实盘仓位，不凭 2026 年仍存在的股票倒推历史股票池，不展示假想净值，不为了产出 Top N 而强制填充候选。

## 3. 产品信息架构（保留已有模块和视觉语言）

保留现有 `lab`、`screen` 路由、卡片/KPI/Tab/表格及浅色组件体系。仅把 `screen` 的默认工作流改成投资机会研究；不要引入新开发平台风、大量状态徽章、长段限制性声明或装饰性图表。

### screen · 个股 Alpha 机会
**首屏（使用优先级从高到低）**
- 单行状态：研究日期/观察截点、股票池数量、入围数量、研究资格、模型与数据最近更新时间。仅在问题影响当前结论时出示局部阻断信息。
- **今日机会表**：代码/行业、机会阶段、H3 条件收益（明确模型版本和资格）、上涨概率、下行概率、预估成本后边际、主要原因、变化方向；提供 H1/H3/H5 切换和阶段筛选。
- **机会阶段**：`EARLY_WARNING`（异动/超跌但卖压未确认）、`EXHAUSTION`（卖压衰竭待验证）、`TRIGGERED_RESEARCH`（规则触发、仍非交易指令）、`INVALIDATED`（逻辑失效）、`INELIGIBLE`（数据/事件/流动性不合格）。阶段不可仅由加权分数硬切。
- **个股证据抽屉/详情**：相对行业收益轨迹、近几日价格/波动/美元成交额、因子贡献、何时进入阶段、L1/L2 条件对比、可用数据时间、已知事件、失效条件。缺失证据直接标出“无法判断”，不可编造。
- **今日漏斗与排除原因**：观察池→证券/流动性合格→有可计算特征→有校准模型预测→通过成本/风险研究检查；展示每层减少多少及常见拒绝原因。漏斗口径可审计。
- **冻结后的后续检验**：按交易日查看冻结研究预测 → 实际 H1/H3/H5 到期收益 → 预测误差 → 研究假设是否成立；未到期按待兑现显示。

### lab · 因子实验室（原模块保留）
- 仍能创建、复制、冻结、预览因子；把技术参数集中到研究设置，默认只展示研究假设、公式、数据覆盖、Rank IC、分组稳定性、样本外证据。
- 自定义 DSL 及版本化实验作为增强项；必须拦截未来函数、滥用参数搜索、混合来源。

### screen · 研究工具二级区
- “因子组配置 / OOS 模型对照 / 策略回测与实验记录”集中为二级研究视图；不占每日首屏。
- 与历史 `/strategies`、`/backtests` 保持链接兼容，旧记录和 API 不删除。
- 错误仅隔离当前模块，不触发整个页面白屏；加载沿用当前旋转 icon 动画。

## 4. 个股逻辑与因子

### 4.1 真实股票池（PIT/forward 分层）
- 优先可观察且数据合格的美股普通股与 ADR（ADR 单独标记），剔除 ETF、ETN、权证、优先股等不兼容证券类型；按交易所、身份、退市/停牌、价格、ADV20、价格源和事件可用性过滤。
- 当前 forward 机会池：实时拉取/轻缓存/按需计算，先以**有限且明示来源的高流动性美股池**为 MVP；不声称覆盖全美股。100–300 只是候选工程范围，需要数据源许可、配额与成本验证后确定。
- 回测研究池：必须有对应交易日可证的历史 membership、企业行为、raw 交易价格与时间戳；不得用当前成分回填旧日。历史资格未满足时允许今日前向记录，但不允历史已验证收益。
- L3 独立维护必要历史价格/因子窗口；不把多年全市场库推给 L1。历史行情参与滚动训练，避免“纯当天快照假预测”。本地仅保存轻缓存、哈希化快照、冻结输入和可审计输出，源数据按需获取且遵守许可。

### 4.2 机会形成（有过程，不只是结论）
- A 超跌程度：1/3/5 日收益、行业残差反转、短期偏离；区分市场普跌与独立错杀。
- B 卖压衰竭：ATR/realized volatility 变化、量能冲击/收缩、收盘区间位置、下跌创新低力度、日内反弹位置。
- C 恢复确认：相对行业转强、关键价格/成交确认、是否继续弱于板块。
- 设置明确观察阶段变化和证据，不把涨得最多的股票直接定义为“机会”。
- 所有特征版本化、只使用截至 T 信号时实际可得值；按行业分组标准化，缺失标记显式化，避免小样本漂移和可疑补值。
- 初期使用可解释的 8–12 个主要因子、Ridge+Logistic；LightGBM 等复杂模型必须通过固定 OOS 协议后再引入。

### 4.3 模型与条件增量
- 标签：T 的信息→T+1 open→T+H close 的 raw 总收益与行业/基准超额收益，扣费指标单列；公司行为单独处理；按 H1/H3/H5 独立训练/校准。
- A Alpha-only；B Alpha+L1；C Alpha+L2；D Alpha+L1+L2。**仅有经相同样本、相同标签、样本外配对比较有增量的模型，才能在机会排序里使用条件权重。**
- 如果 L1/L2 当前未达到准入或没有相同日期 PIT 条件：仍可显示 A 的研究候选，标明“仅 Alpha 研究”，**不能假设 B/C/D 已可用**，更不能把预测直接输给执行资格。
- 采用日期滚动训练、purge 与至少 5 交易日 gap、训练内标准化、独立校准和与最简单基准比较；模型版号/特征版号/来源快照/决策时钟一起冻结。

## 5. 排序规则与每日结果契约

分两道门：
1. **发现/研究门**：证券有效、数据质量合格、事件已核查、可解释的机会阶段、预测来源清楚，排序同时考虑预期超额收益、概率与不确定性；未校准概率不能展示为可信交易概率。
2. **风险/执行门**：由 L4 基于真实账户、成本、流动性、行业集中度、止损与风险预算另行判断。现有 `PlanPolicy` 可以复用，但不能将其研究性 `indicative_weight` 当实盘仓位。

预定义空状态：
- 股票池来源不足 → DATA_BLOCKED（给出单一最重要原因）；
- 特征已可观察但没有合格历史模型 → WATCH_ONLY；
- 有研究预测但成本/风险门未过 → NO_QUALIFIED_OPPORTUNITY；
- 未到 T+H → AWAITING_OUTCOME；
- 无符合条件的股票 → NONE（正常结果）。
严格禁止为了 Top5 强制补足候选。

## 7. 必须验收的量化证据

- **正确性**：每个 T 信号的特征 `available_at <= signal_time`，T 之后结果不得混入；退市、拆股、分红、停牌、跳空、成交时间均有明确处理或阻断。
- **预测能力**：H1/H3/H5 分开输出 Rank IC/ICIR、相对朴素基线的收益误差、Brier/LogLoss、概率校准曲线、覆盖率、样本数量与分市场环境效果。
- **研究增益**：A/B/C/D 配对、市场与风格条件消融、区块自助法置信区间和多重试验控制；展示成功、失败与样本不足。
- **策略证据**：只在严格原价成交和公司行为路径可靠后，比较成本后净收益、回撤、换手、滑点敏感性与现金/行业/简单反转等基准。预测排名≠回测收益。
- **前向验证**：持续冻结真实当日预测，不得事后修改信号和阈值；样本未达门槛明确 NOT_READY。
- **体验**：默认读到候选/无候选；点进一只股票就能看到“机会来自哪、变化了什么、依据是否可靠、何时失效”；不再让用户先创建因子、配权重才能使用 L3。
