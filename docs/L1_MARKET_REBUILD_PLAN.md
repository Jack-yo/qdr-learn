# QDR L1 市场预测：12 维观测、条件预测与验证体系重建方案

> 版本：2026-11-14 / L1 Architecture v1.0。基线：`main e6cdf7a`。仅重构 L1；L2 风格、L3 Alpha、L4 风控保持不变。**本文为工程目标与分期验收，不表示 12 维数据均已接入、模型已有有效预测或已有交易资格。**

## 0. 北极星目标与边界

让系统在每个美股交易日收盘后，基于**当时已到达且来源可核查**的数据，自动完成跨资产及股票横截面扫描、滚动指标计算、变化/背离检测、领先性检验，形成未来 H1/H3/H5 的收益分布、波动、尾部风险和“先反弹/先下跌”竞争事件预测。降低手动切换图表和重复计算，而不是强迫输出每日买卖建议。

需要保留四层导航和既有 L2/L3/L4 API；L1 输出可作为后续条件信息，未通过独立样本外实验不得给予决策权重。旧 `market_state` 四状态保留为**可选历史描述**，不再是 L1 预测主目标。严禁把 Yahoo 回溯概率、当日收盘后才采集的历史数据冒充当时真正冻结的预测。

## 1. 现状与主要缺口

- `features/states.py`：已有 SPY 收益与实现波动、RSP/SPY、HYG/LQD、行业 ETF 相关性与 ETF 广度代理；缺真实 PIT 股票广度、波动隐含结构、资金/订单流和可验证领先特征资格。`frozen_states` 基于过去 20 日涨跌和波动阈值，属于滞后描述。
- `workflow/v4_market.py` 与 `models/v4_oos.py`：可做严格时点输入的滚动研究、Ridge/Logistic、校准和样本外评分；现有预测输出不足以代表完整路径和条件事件模型。
- `workflow/v4_freshness.py`：已区分行情新鲜度与预测资格，值得复用。
- `workflow/v4_daily.py`：保留现有六阶段日终编排；第一阶段只增加旁路观测，不提升 `PASS`/可交易资格。
- `docs/G4_market_research_acceptance.md`：既有 2023–2024 Yahoo 研究中 H1/H3/H5 Brier 均不优于常数基准，且不具备历史 PIT 预测资格。此为旧实验，不等于最新 V4 正式验证。

## 2. 十二维观测体系：注册、证据与实施策略

| 维度 | 代表特征（不预设有效） | 供给 / 时点风险 | 优先级 |
| --- | --- | --- | --- |
| 01 价格与趋势 | 1/3/5/20D 收益，动量加速度，隔夜/盘中收益，收盘位置 | OHLCV、交易日历、公司行为 | P0 |
| 02 真实股票广度 | 上涨占比、MA20 上方、20D 新低比例、下跌成交额占比、A/D | 全历史 PIT 股票身份/退市 + 当时收盘数据 | P0（数据阻断时仅观察 ETF 代理） |
| 03 波动结构 | RV5/RV20、下行半方差、跳跃/隔夜风险、VIX/VVIX/期限结构 | 股票 RV 可先做，隐含波动需要授权历史 | P0/P1 |
| 04 期权风险定价 | 25Δ skew、VRP、期限斜率、尾部保护价格 | 到期/执行价对齐、期权时点、许可 | P1 |
| 05 期权仓位/对冲 | OI 期限/价位集中、Gamma 情景、0DTE 活动 | OI 非 dealer net position，不得直接宣称净 GEX | P2 |
| 06 微观结构 | spread、深度、订单失衡、有效价差、价格冲击 | 需要逐笔/盘口，日线无法推算 | P2 |
| 07 相关性与离散度 | 股票/行业相关性、同步下跌比例、离散度 | PIT 横截面、回报口径统一 | P0 |
| 08 跨资产压力 | 美债收益率、信用利差/ETF 代理、美元、MOVE、金价 | 发布时点、资产交易日不一致 | P1 |
| 09 拥挤与持仓 | ETF 申赎/资金流、期货 COT、真实短仓代理、集中度 | 数据延迟；短卖成交量不能冒充空头持仓 | P2 |
| 10 宏观与事件 | CPI/FOMC 已知发布日、实际惊喜、财报集中度、期权到期 | 公布时点与首次发布值；禁止修订后回填 | P1 |
| 11 融资条件 | 货币市场利差、融资压力、银行/金融条件 | 周频和修订值不可直接当作当天已知 | P2 |
| 12 未来路径事件 | 先触及上/下界、MFE/MAE、缺口、尾部损失 | 需严格 T+1 open 交易窗口；同根日 K 双触及无法排序 | P0 |

**注册规则**：每个特征记录 `feature_id`、定义、单位、频率、滞后、lookback、原始来源、`available_at`、首次可得版本、缺失规则、PIT 资格、模型资格、校验/版本摘要。P0 先落地约 20 项基础观测，之后逐批扩展；“80–150 特征”仅为候选容量目标，不是承诺有 80 个有效预测因子。

## 3. 统一数据契约与质量门控

输入逻辑表：`l1_daily_bars(date, security_id, symbol, OHLCV, available_at, price_basis, source, receipt_id)`；`l1_universe_daily(date, security_id, is_member, available_at, provider_identity)`；`l1_session_clock(date, decision_cutoff_utc)`；`l1_external_series(series_id, observation_date, value, released_at, revised_at, version)`。

- 所有 `date` 为美股交易所日，时间戳 UTC-aware。按 `decision_cutoff_utc` 拒绝晚到的价格、成员及外部数据；当日不存在的未来标签不得进入预测特征。
- 每个日期股票池既需要**成员身份完整性**，也需要**有效行情覆盖率**；若 PIT 身份未独立审计，则只输出 `RESEARCH_ONLY_UNATTESTED_PIT`，无交易资格。未获得全量成员时不把“有数据的股票”冒充全市场。
- 计算 20D 指标时单股必须有连续足够多的有效交易日；未知 IPO/停牌/退市、公司行为和缺失者不得默认为 `False/0`；披露覆盖分母、样本数和缺失理由。
- 统一原价与复权口径，收益/成交金额不同用途分开；本阶段仅按已传入价格计算研究观察，不宣称公司行为资格。
- 数据供应商及许可：可在当前仓库的 Alpaca SIP 和已存在原始数据库基础上接线；期权/宏观/利率数据单独审计 API 历史范围、延迟、历史版本与使用许可，不“接入一个 ticker”代替完整期权数据。

## 4. L1 预测实验与数学定义

统一 T 日收盘后冻结信号，未来窗口为 `T+1 open -> T+H close`，`H∈{1,3,5}`。

1. **E01 风险预测**：条件未来实现波动、下行半方差、尾部/区间最大不利波动。基准历史滚动、EWMA，挑战 HAR-RV/GARCH 等（HAR-RV 需要相应已验证的日内或替代测度）。检验 QLIKE/适当波动损失、覆盖率及极端风险误报。
2. **E02 压力衰减/路径先触及**：研究 `P(先触及上界 | X_T)`、`P(先触及下界 | X_T)` 及两者都未触及。候选阈值在训练集固定，以波动率标准化目标做稳健性；同根日线同时跨上下界者标 `ORDER_AMBIGUOUS`，不得自行排序。基准历史条件频率，候选多项/竞争风险模型。
3. **E03 条件收益分布**：预测 `F(R_T,H | X_T)`，输出分位、均值、上涨概率和尾部事件。基准滚动无条件/条件历史分布；候选正则化/分位数回归、树模型。要求概率或分位数校准、CRPS/Pinball、覆盖和基准增量。

在 E01–E03 之外，`regime`、变化点、HMM 是候选辅助模型，只有在滚动样本外有增量才进入预测层。模型复杂度通过消融实证决定，而不是为了凑满 12 维。

## 5. 模型研究协议与反数据挖掘

- 预注册目标标签、阈值候选集合、训练/校准/测试切分、信息到达规则、评分和停止条件；保持独立未见样本，重复检查过的年份不再称为独立最终测试。
- Purged walk-forward + embargo、每折仅使用当时已经发布的特征和已完成的结果；滚动窗口和阈值只在训练折选取；波动聚集和 H3/H5 重叠使用按交易日的块 bootstrap/HAC 等依赖稳健方法。
- 每个特征组记录 `baseline -> +new_group` 的配对 OOS 差异、模型稳定性、数据覆盖、误报与提前量。高相关变量不能重复记功，研究过的假设包括失败结果都保留。
- 预测质量：Brier/LogLoss、Pinball/CRPS、QLIKE、覆盖率、尾部事件 PR/召回、误报次数、提前量和事件频率；交易效用属 L3/L4 联动验证，不以 L1 的 AUC 或 IC 替代净收益。
- 真实前向必须冻结模型版本、特征快照摘要、预测生成时间、数据回执及原概率。之后追加观测结果，不重算覆盖原预测。没有足够校准/事件数的罕见尾部预测返回 `N/A`。

## 6. 自动日终观测与 UI 数据接口

**日终链路**：交易日历校验 → 源数据与公司行为完整性核查 → 12 维可用数据刷新 → 特征批计算 → 变动、历史 z-score、背离候选扫描 → OOS 合格模型推理 → 冻结 → 前向到期结算 → 前端摘要。

建议后续只读资源：
- `/api/v1/l1/observations?asof=&horizon=`：实际观察、时点、覆盖率、缺失与资格（不混入预测）。
- `/api/v1/l1/anomalies?asof=`：历史分位/异常/背离候选，必须标注观测与领先性未验收。
- `/api/v1/l1/forecast?asof=&horizon=`：仅经独立验收后输出前瞻概率、分位与冻结证据；否则返回 `BLOCKED`。
- `/api/v1/l1/validation?model_version=`：基准比较、OOS 样本与失效区间。

L1 UI 首屏只保留：未来路径展望、当前变化（异常/背离）、证据（模型与数据可靠性）。历史演变、特征实验和验证下钻不需要先设计为多层子页面。不要假装异常等于预测。

## 7. 交付阶段、顺序和客观验收

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| A · 本次启动 | L1 完整改造规格、12 维注册表、研究-only 计算器、时间/覆盖门控、异常扫描、单元测试 | 合成数据确定性测试通过；缺 PIT 不输出真广度、无未来数据泄漏、无虚构预测 |
| B · 数据拓展 | 基于现有数据仓库实现可复现日终输入适配与 P0 市场价格/股票广度/相关性/波动/路径标签 | 每个维度有 `available_at`、coverage、证据源；真实历史 PIT 缺失则明确阻断 |
| C · 基础模型 | E01、E02、E03 基准与挑战模型，统一时序评价 | 有可复核的 OOS 逐日预测及失败记录，不能用合成样本声称有效 |
| D · 连续运转 | T 日冻结与 T+H 结算、异常变化解释、预测稳定性、模型淘汰 | 可审计连续多日真实前向结果；数据错漏或模型不过关明确 BLOCKED |
| E · 产品重构 | L1 主页 + 必要研究下钻，保留四层结构 | 用户不必逐个计算指标；每项显示来源、领先证据和限制 |

**本次阶段 A 的明确限制**：仅新建旁路研究模块和独立 CLI，暂不修改原市场研究 API、已有 forecast 归档协议、四层路由或生产预测资格。CLI 不负责拉供应商数据，也不接受合成结果作为实盘预测。阶段 B 依赖当前工作机的完整历史数据、证券身份及有效授权。
