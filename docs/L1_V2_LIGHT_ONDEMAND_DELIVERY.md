# QDR L1 V2：按需取数、轻量缓存和综合市场研判

版本：2026-11-14。只改 L1 和新增轻量数据读接口，L2/L3/L4 保留。该版本是**研究观测**，绝不自动启动交易。

## 0. 与旧 L1 的关系

- 新界面 `/#market` 第一屏增加：上涨动能、下跌压力、压力衰减、H1/H3/H5 历史相似条件、即时异常、12 维覆盖及逐指标下钻。
- 旧 E01/E02/E03 冻结预测及全部研究功能保留在可展开区；**不会**用未验证的历史频率替代正式冻结预测。
- V2 不要求建立完整个股历史 OHLCV 仓库；首次打开 L1 时通过供应商接口批量按需获取一个有限研究窗口（默认 530 日历天），结果缓存在 `data/cache/l1_on_demand`。
- 可选 CLI 仅保存很小的逐日研究**摘要**，而非全量行情；缓存有 TTL、单条最大尺寸、总容量和条目数限制。保护源数据许可；缓存不是 PIT 独立证明。

## 1. 本地配置与运行

复用原项目 `ALPACA_API_KEY` 和 `ALPACA_SECRET_KEY` 环境变量（永远不要提交凭证）。

可选项：

| 变量 | 用途 | 默认 |
| --- | --- | --- |
| `QDR_L1_FEED` | `delayed_sip`, `sip`, `iex`（需与权限一致） | `delayed_sip` |
| `FRED_API_KEY` | 美国国债利率、SOFR、高收益信用利差 | 未配置则标记缺失 |

不推荐无条件回退至 IEX：IEX 只是单交易所数据，不能冒充全美汇总行情。`sip` 实时权限若不足，供应商会返回 `HTTP_403`，而不是“假装实时”。`delayed_sip` 也受实际授权限制。

启动原项目后访问 `/studio#market`。请求新接口：

```text
GET /api/v1/l1/v2/overview?horizon=1
GET /api/v1/l1/v2/overview?horizon=3
GET /api/v1/l1/v2/overview?horizon=5
GET /api/v1/l1/v2/overview?horizon=3&refresh=1
```

该 API 只接收上述两个参数；异常或无法获取合格数据返回 HTTP 409 和结构化阻断原因。

也可以运行一次独立的市场扫描（无需由 Codex 手工生成数据文件）：

```bash
python -m quant_research.workflow.l1_v2 --root .
python -m quant_research.workflow.l1_v2 --root . --refresh --save-summary
```

第二条命令保存 `outputs/l1_v2_daily/YYYY-MM-DD.json` 不可覆盖日报。用户可以在本机任务计划程序定时执行；不为本地电脑擅自安装后台任务。

## 2. 数据源和实际覆盖

| 数据源 | 接口 | 主要用途 | 核查状态 |
| --- | --- | --- | --- |
| Alpaca 股票 ETF | `GET /v2/stocks/bars` | 19 只 ETF 日线、动量、波动、信用与广度**代理**、板块分化 | ChatGPT 连接端实测可取 SPY/QQQ/IWM；本地要求有效 API 凭证 |
| Alpaca Level-1 | `GET /v2/stocks/snapshots` | 最新成交、SPY 一档价差（不是全市场订单簿） | 依供应商行情权限而定 |
| Cboe VIX | 官方 VIX 历史收盘 CSV | VIX 风险观察（非完整期权偏斜） | 按需网络请求，必要时 `MISSING` |
| FRED | `fred/series/observations` | DGS10、SOFR、高收益信用利差 | 需要 `FRED_API_KEY`；仅用当前版本，不冒充历史 PIT |

十二个维度都展示覆盖状态：`OBSERVED`、`PARTIAL`、`MISSING`。现阶段期权完整仓位/对冲、全市场逐笔盘口、ETF 真实申赎、宏观事件意外值、历史退市 PIT 股票广度等不可能仅通过上述公开行情保证完整，**必须显示缺口**。

## 3. 综合评分规则（非预测概率）

所有历史相对特征在日期 T 只使用过去至少 40 个、最多约 100 个交易日的均值与标准差，得到有上限的 z-score（绝不使用未来时点拟合的标准化参数）。

- 上涨动能 = 50% SPY 五日走势 z + 25% RSP/SPY 五日相对收益 z + 25% IWM/SPY 五日相对收益 z。
- 下跌压力 = 30% RV5/RV20 z + 25% 下行实现波动 z − 25% HYG/LQD 五日相对收益 z − 20% SPY 五日收益 z。
- 压力衰减 = 五个交易日前的下跌压力 − 当前下跌压力。
- 展示指数：`clip(50 + 15 × 指数, 0, 100)`。50 为对比中性值，不是涨跌 50% 概率。三个评分的经济含义及共线性须后续实证核验。
- 异常：当前数据与时点之前滚动窗口的 z-score 比较，阈值 |z|≥1.8，展示异常、非自动交易信号。

## 4. H1/H3/H5 条件研究口径

- 使用历史价格代理（非公司行为总回报）；训练时信号日 T 的特征只能由 T 日收盘及之前的数据计算。
- 以 T+1 开盘 → T+H 收盘定义未来价格收益。
- 相似历史：按三个市场结构评分的距离取最多 75 个已到期历史窗口，至少有 25 个有效权重样本。
- 计算历史相似样本上涨频率、均值、Q10/Q25/Q50/Q75/Q90、先触及上 +2% / 下 −1.5% 的三类条件频率。
- 一根日线同时碰上下界且顺序不明时计为 `AMBIGUOUS`，不强行分配。歧义太多或有效样本不足则不展示路径频率。
- 历史滚动检查使用**已结算**的历史条件估计与无条件基准对照，报告 Brier 与样本数。由于未独立证明 PIT/未独立保留盲测，**永远输出 `RESEARCH_ONLY`，不宣称校准或交易资格**。
- 经过样本外验证后，可将评分作为原 E01/E02/E03 候选输入，但本次没有擅自替换正式预测算法。

## 5. 缓存与存储边界

- `BoundedCache` 容量上限 32MB / 32 条 / 单响应 5MB；源响应存入限量文件，过期与容量溢出会淘汰，不持久建设历史行情仓库。
- 历史 ETF 批量行情缓存 15 分钟，最新快照 60 秒，Cboe/FRED 2 小时；手动强制刷新绕过缓存。缓存 key 不包含凭证，响应没有供应商密钥。
- 部分来源需付费，遵守来源许可；永久保留研究摘要不代表可永久保留受许可保护的原始行情。
- 预测用于未来真实研究时，必须独立保存不可覆盖的时点归档及来源回执；只能在数据截止时间之后合法形成，不能通过晚到历史回算倒填。
