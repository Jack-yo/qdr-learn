# QDR L1 非数据代码交付核验（2026-11-14）

**完成的非数据工程代码**：12 维特征定义/缺失处理、可用 OHLCV 及部分跨资产派生量、可选真实传感器和数学转化、E01 未来波动、E02 首次触及事件、E03 条件收益分位研究、按时间间隔隔离的样本外评价、实验结果和缺失状态归档、T 日冻结接口、哈希校验和只读 API、L1 单页响应式交互、期限筛选、异常、验证对照和日期回放。

**不能用无数据代码替代的实证交付**：12 维真实供应商历史源、完整证券池 PIT 与公司行为、当前数据源和交易日截止回执、模型最新样本外实证是否优于基准、真实前向连续追踪结果、用户环境端到端验收。这些必须在 Codex 完成数据源接入后执行。没有这些证据，`MODEL_OOS_ADMITTED` 和真实交易依然阻断。

**客观限制**：
- 57 个注册指标不是 57 个有效预测变量，不是每项都有数据，也不是每项都有算法估计值；只有可计算量和已收到真实来源的 optional 实际显示。
- E01/E02/E03 是可运行候选研究模型，不承诺未来收益优势。E03 上涨/下行概率未经过独立概率校准时明确为 `NOT_CALIBRATED_RESEARCH_ONLY`。
- 真实日线同日高低价双触及时，无法确定价位先后，事件标为 `AMBIGUOUS`，不列入三分类模型的已知事件样本。
- 市场展望没有把 Yahoo 历史实验自动推升为当前预测，也不使用模拟交易盈利。
- 合成数据单元测试只验证合同、数学与时间因果性；不替代真实数据模型/性能检验。
