# QDR V4 高保真界面 · 设计到代码对照（2026-11-11）

## 设计来源

以用户确认的《QDR_四层架构_交互预览.html》为视觉与信息架构基准（原样稿为演示数据，**不可作为实际模型成果**）。主视觉采用深蓝背景、264px 左侧导航、66px 全局顶栏、统一卡片与表格、青绿/蓝/紫/橙状态色，保持清晰的四层研究层级。

代码不直接部署样稿中的假概率、伪造候选、收益热图或模拟 P&L，而是以真实数据+缺省状态重建内容。

## 本轮实际交付

- **主入口**：`http://127.0.0.1:8766/` 和 `/studio`，均打开新 `src/quant_research/v4_shell.html`。
- **旧版完整功能**：原 `/overview`、`/market`、`/styles`、`/factors`、`/strategies`、`/backtests`、`/paper`、`/data` 等保留。为防止影响原有复杂操作，旧页面有「返回 V4 主工作台」入口。
- **视觉系统**：`v4_shell.html` 复用已确认样稿的深色视觉框架，补充响应式滚动、表单、状态与交互反馈；不覆盖旧站样式，不删除已有工具。
- **数据和交互**：`v4_ui_core.js` 和 `v4_ui_pages_a.js / b.js / c.js` 实现页面、导航、无模拟值的占位、服务端实际 API 读取与异常状态。

## 用户可以进行的操作

1. 直接打开根目录 `/`，按样稿六个页面的统一左侧导航切换；
2. 从「自定义因子实验室」填写公式，保存不可变因子版本，使用真实数据进行预览或提交实验；
3. 从「因子组选股」选取已完成实验，配置权重（总和 100%），保存策略，选择版本查看真实候选与统计结果；
4. 在市场、经典因子、持仓风险页切换研究范围、选择历史因子、查看真实风险与账本；
5. 打开原有详细工作台进行深度参数编辑、策略资格预检、完整回测审阅或数据质量维护。

## 验证证据与未完成项

**已验证**：四个新增 JS 模块已通过代码解析；针对有数据和无数据两类输入，各页面的生成函数已在纯 JavaScript 隔离测试中运行；新增 `tests/test_v4_ui_shell.py`，覆盖页面层级、资源引用和连接方式。此处是代码/静态执行检查，不是已通过真实浏览器 E2E。

**待验收**：最新版完整 Python 环境的 pytest、实际浏览器截图/布局回归、多端视口（1440/1920/移动）、因子 POST→任务执行→报告的真实后端测试，以及独立 PIT 数据资格/概率和策略绩效。当前旧版详细工作台仍用浅色视觉；如需无断层视觉一致性，可在后续迭代将其表单功能搬入 V4 子页面。

**重要**：任何页面有数字必须来自实际仓库/归档，并注明是历史描述、预测研究、严格回测还是模拟账本；缺数据保留空态。不可用静态高保真示例冒充真实预测效果。
